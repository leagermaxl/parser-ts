# parser-ts

Парсер заказов megagroup.ru: собирает заказы, считает выплаты по купонам и выгружает Excel-отчёты.

## Установка

```bash
yarn install
cp .env.example .env
```

Заполните `.env`: `MCSID` (кука сессии), `URL_PAGE` (страница списка заказов), `URL_ORDER` (страница одного заказа).

## Запуск

- Windows: двойной клик по `start.bat`
- macOS/Linux: `./start.sh`
- Вручную: `yarn start`

Откроется меню:
- **Запуск работы Бур-машины** — собрать заказы и выгрузить xlsx-отчёты в папку с сегодняшней датой
- **Сохранение конфига** — сохранить снэпшот `config.json` в `config-backups/`
- **Выбор конфига** — восстановить `config.json` из сохранённого снэпшота
- **Выход**

Перед каждым запуском `config.json` бэкапится автоматически.

Если `MCSID` протух, Бур-машина покажет `Токен устарел, обновите его.` — нужно обновить токен в `.env`.
